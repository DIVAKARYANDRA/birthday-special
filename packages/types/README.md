# packages/types

Shared TypeScript types consumed by both apps/web and apps/admin, per
docs/01-system-architecture.md, Section 3 ("packages/types") and
docs/04-backend-architecture.md, Section 7 (OpenAPI schema as the contract
source of truth).

## Status
Foundation only (Prompt 7). Intended to eventually be generated from
services/api's OpenAPI schema rather than hand-maintained, once real API
endpoints exist to generate from. No types are defined yet.
