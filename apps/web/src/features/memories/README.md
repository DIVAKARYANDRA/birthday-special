# features/memories/

New as of Prompt 15 — not part of Prompt 7's original scaffold, which had
no dedicated `memories` feature folder (Prompt 1's original scene list
folded memory browsing loosely into "Gallery"). Prompt 15, Part 3
explicitly separates "Memory Garden" from "Gallery" as distinct World Map
locations with distinct Parts (5 and 7 respectively) — this folder is the
sanctioned home for Part 5's "Memory Experience," created because Prompt
15 itself requires it, not as an unprompted architectural change.

See `data.ts`'s own docstring for the important scope note about
placeholder data — no Public Experience API exists yet to fetch real
Memory content (Prompt 13's `memories` domain only has an ADMIN API,
per Prompt 14).
